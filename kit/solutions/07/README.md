# Boutique Vue (starter)

Point de départ du lab « Vue avancé ». Voir `AGENTS.md` pour les règles du projet.

```bash
npm install
npm run dev        # http://localhost:5173
```

Par défaut l'API est https://dummyjson.com. Hors ligne : `cp .env.local.example .env.local`
puis lancer le serveur du kit (`kit/server`, port 4310).
